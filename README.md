SauceDemo UI Automation

Automated UI test suite for https://www.saucedemo.com/ using Java, Selenium, and TestNG.

- Java 21
- Selenium WebDriver
- TestNG
- Chrome (headless)
- Maven
- Page Object Model (POM)

Project Structure

Sauce_Demo_Test
├── pages/ # Page Object classes
├── tests/ # TestNG test classes
├── utils/ # Driver setup
├── pom.xml # Project dependencies
└── reports/ # Test reports
